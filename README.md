CAMPUS STORE MANAGEMENT SYSTEM

1. Project Overview

The Campus Store Management System is a C++ based project designed to manage products and billing in a college campus store. It allows users to add products, display product details, generate bills, and apply discounts.

This project demonstrates two programming approaches:

- Procedural Programming
- Object-Oriented Programming (OOP)

2. Objectives

- To manage products efficiently.
- To generate customer bills.
- To calculate discounts and coupons.
- To understand the difference between procedural and OOP approaches.
- To implement basic programming concepts in C++.

3. Features

- Add new products.
- Display all available products.
- Generate bills.
- Apply percentage discounts.
- Apply coupon discounts.
- Calculate final prices.
- Maintain product count.
- Audit product details.

4. Technologies Used

- Programming Language: C++
- IDE: Visual Studio Code
- Compiler: GCC (MinGW)
- Concepts: Functions, Structures, Classes, Objects, Constructors, Encapsulation and Function Overloading.

6. How to Run the Project

1. Open the project folder in VS Code.
2. Open the required C++ file.
3. Open the terminal.
4. Compile the program using:

g++ OOP1.cpp -o OOP1

5. Run the program using:

.\OOP1.exe

For other versions, replace the filename accordingly.

8. Conclusion

This project helps in understanding how a Campus Store Management System can be implemented using both procedural and object-oriented programming. It also demonstrates the use of C++ concepts in solving a real-world problem.
